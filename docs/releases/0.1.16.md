## What's Changed

* Choose a subscription model from your local Magpie setup in **Settings → General**. Models that support screenshot questions are marked **Images**.
* Set up an API key by copying a setup prompt for your assistant or configuring it manually. When switching from a subscription, Howler keeps your current model active until the new one passes **Save & Check**. If you cancel or the check fails, your subscription stays active.
