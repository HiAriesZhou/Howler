## What's Changed

* Start the same region capture from Shortcuts by opening `howler://capture`. Drag the region to send it. A link with a question, image or any other parameter does nothing.
* The newest question and answer sit just below the writing line. Scrolling down keeps your place while that answer grows, and sending a question returns to the top.
